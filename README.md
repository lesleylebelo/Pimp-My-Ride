# PimpMyRide

A mobile marketplace connecting vehicle owners with **vehicle customization shops**.

PimpMyRide allows customers to manage multiple vehicles under one account, post service requests for their vehicles, and receive quotations from verified customization shops. Customers can compare quotations, choose a suitable shop, and book an appointment.

Customization shops can create business profiles, list their services, respond to customer requests, and showcase completed projects to attract new customers.

## Project Status

**Currently under development**

This repository contains the ongoing development of the PimpMyRide mobile application.

## Planned Core Features

* Customer accounts and profiles
* Multiple vehicles per customer account
* Vehicle Garage
* Service requests with vehicle images
* Marketplace feed
* Verified customization shops
* Shop services and portfolios
* Quotation submission and comparison
* Workshop bookings
* Ratings and reviews
* Location and map functionality
